# CleanSheet — Data Cleaning and Auditing

## Overview

CleanSheet is a Python-based project that audits and cleans CSV datasets using Pandas. It identifies duplicate records, missing values, completely empty rows and columns, and invalid data in supported age and email columns.

The project demonstrates a simple, reusable workflow for improving dataset quality and verifying the cleaned output.

## Features

- Load CSV datasets using Pandas
- Inspect dataset shape and column data types
- Detect and remove duplicate records
- Identify missing values
- Detect completely empty rows and columns
- Handle missing age values
- Identify invalid or negative age values
- Validate email formats when an email column is present
- Export cleaned datasets to CSV
- Verify the saved output using a final audit

## Technologies Used

- Python
- Pandas
- Regular Expressions
- Jupyter Notebook
- Google Colab

## Dataset

The project uses the **Iris dataset** to demonstrate the data-cleaning workflow. A separate test dataset is used to demonstrate age and email validation.

The Iris dataset contains measurements of iris flowers and their species.

## How to Run

### Option 1: Run Locally

1. Clone or download this repository:

   ```bash
   git clone https://github.com/<your-username>/CleanSheet.git
   cd CleanSheet
   ```

2. Install the required library:

   ```bash
   pip install -r requirements.txt
   ```

3. Open the notebook from the `notebooks/` folder using Jupyter Notebook or JupyterLab:

   ```bash
   jupyter notebook notebooks/CleanSheet_Data_Cleaning_and_Auditing.ipynb
   ```

4. Run all cells in order. The notebook loads `../data/raw/iris_dataset.csv` and saves the cleaned file to `../data/processed/iris_cleaned.csv`.

The paths are relative to the notebook's own folder, so keep the folder layout above intact.

## Results

The final verification of the cleaned Iris dataset showed:

- **Original dataset:** 150 rows and 5 columns
- **Cleaned dataset:** 147 rows and 5 columns
- **Duplicate rows remaining:** 0
- **Missing values remaining:** 0

The cleaning workflow removed three duplicate rows and verified that the resulting dataset contained no duplicate records or missing values.

Age and email validation are demonstrated separately because the Iris dataset does not contain age or email columns.
